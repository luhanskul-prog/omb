Upload Subject Marks Excel

Upload a completed Excel mark sheet. The assessment is taken directly from Assessment & Marks Management. Only OPEN or REOPENED assessments can receive marks. The Excel file may contain all permitted subjects. Each learner and subject is validated before saving.
Mark Entry Permission
  • Administrators may upload marks for all classes and subjects.
  • Class teachers may upload all subjects for their assigned class.
  • Subject teachers may upload only their assigned subjects and classes.
  • The Excel file may contain multiple subjects.
  • Each learner-subject combination is validated separately.
  • Unauthorized Excel uploads are rejected by the server.
  • If any row contains an error, no marks from that file are saved.
